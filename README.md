# Flexo

**Ctrl + Enter. Your text, instantly better.**

Flexo is a lightweight Chrome extension that improves your writing anywhere you type.

Fast, simple, invisible.

---

## Features

* Instant text optimization
* Works directly inside websites
* Floating minimal UI
* Keyboard shortcut support
* Multiple writing tones
* Fast OpenAI-powered processing

### Tones

#### Neutral

Fix grammar and spelling while preserving your natural voice.

#### Professional

Turn rough messages into clean, polished communication.

#### Persuasive

Make your writing clearer, stronger, and more convincing.

---

## Shortcut

```txt
Ctrl + Enter
```

Optimize text instantly.

---

## Philosophy

Flexo is designed as a reflex tool.

No tabs.
No copy-paste.
No bloated AI workspace.

Just write normally and improve text in place.
